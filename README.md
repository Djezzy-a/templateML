# Machine Learning

Код и эксперименты находятся в `.ipynb`. Здесь — только краткая шпаргалка по основным терминам.

## Основные понятия

**Регрессия** — предсказывает число.  
Пример: цена дома → 300 000 $.

**Классификация** — определяет категорию.  
Пример: письмо → спам / не спам.

**Кластеризация** — сама объединяет похожие объекты в группы.  
Пример: разделить покупателей по поведению.

**Train** / **Test** — данные делят на две части: на одной модель учится, на другой проверяется.
  Например, есть 1000 домов с известными ценами:
  800 домов (80%) → Train — модель учится находить зависимость цены от признаков.
  200 домов (20%) → Test — модель получает эти дома впервые и пытается предсказать их цены.
  Если на Train модель ошибается на 10 000$, а на Test 50000$, значит она могла переобучиться.
  Обычно используют 80/20 или 70/30. Test не должен использоваться для обучения, иначе проверка будет нечестной.

**Переобучение (Overfitting)** — модель слишком хорошо запомнила обучающие данные, но плохо работает на новых.  
Пример: выучил ответы на тест, а на похожих вопросах тупишь.

**Недообучение (Underfitting)** — модель слишком простая и плохо работает даже на обучающих данных.

## Метрики

**MSE** — средняя квадратичная ошибка. Чем меньше, тем лучше. Большие ошибки штрафуются сильнее.

**RMSE** — корень из MSE. Ошибку проще воспринимать, так как она примерно в тех же единицах, что и прогноз.

**R²** — показывает, насколько хорошо модель объясняет данные. Обычно ближе к **1** — лучше.

**Accuracy** — доля правильных ответов. Например, 90 правильных из 100 = 90%.

## Обработка данных

**Медиана** — центральное значение отсортированного набора. Хорошо подходит для заполнения пропусков, потому что меньше зависит от выбросов.

**Категориальные признаки** — значения вроде города, цвета или типа жилья. Для модели их обычно переводят в числа.

**Масштабирование** — приведение признаков к сопоставимому масштабу. Особенно важно для алгоритмов, использующих расстояния.

## Модели

**Линейная регрессия** — ищет прямую зависимость между признаками и целевой переменной.

**Полиномиальная регрессия** — позволяет описывать более сложные, нелинейные зависимости. Слишком высокая степень может привести к переобучению.

**Pipeline** — объединяет обработку данных и модель в одну последовательность.

## Главное

- **MSE / RMSE ↓** — лучше
- **R² ↑** — лучше
- **Train намного лучше Test** → возможно переобучение
- **Регрессия** → число
- **Классификация** → категория
- **Кластеризация** → группы
